# Onboarding

1. Request a sandbox account from your Example Freight Co. account manager.
2. Create an API key in the partner portal. Sandbox keys start with `sbx_`.
3. Send a test shipment to the sandbox endpoint and confirm you get a tracking number back.
4. Ask for production access once ten sandbox shipments succeed in a row.

Production keys start with `prd_` and expire every 90 days.
